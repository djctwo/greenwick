Greenwick 1.0.1 encrypts the trade screenshots you attach, the same way the journal is encrypted.

## What's new

- **Encrypted screenshots:** new screenshots are saved encrypted (AES-256-GCM) with your journal's key. On disk they can't be read; Greenwick decrypts them in memory only to show them.
- **Existing screenshots are encrypted automatically** the first time 1.0.1 opens (or unlocks, with App Lock on). If that is interrupted, it continues next time.
- **While Greenwick is locked,** no screenshot can be opened, shown or saved.
- **App Lock:** turning it on or changing the password moves every screenshot to the new key, safely; the old key is removed only after every screenshot opens with the new one.
- **Erase All Local Data** also removes all screenshots.

Note: backups contain your trades and settings, not screenshot images (unchanged). Because screenshots are now encrypted with this Mac's journal key, copying the Screenshots folder to another Mac no longer brings them along.

## Install

Requires macOS 14 Sonoma or later. Download `Greenwick-macOS-unsigned.zip` below, unzip it and drag Greenwick.app to Applications (replace the old copy; your journal stays where it is). You can check the download against `Greenwick-macOS-unsigned.zip.sha256`.

This build is not signed with an Apple Developer ID or notarized, so macOS blocks the first launch. Right-click (or Control-click) Greenwick.app and choose **Open**, then **Open** again. If there is no Open button, try to open it once, then go to **System Settings > Privacy & Security** and click **Open Anyway**.
