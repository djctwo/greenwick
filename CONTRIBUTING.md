# Contributing

Thanks for your interest in Greenwick.

- **Bug reports and feature ideas are welcome.** Open an issue with what you
  expected, what happened, and the steps to reproduce it. Please never paste
  real trades, account numbers, broker exports or API keys into an issue. If
  an import fails, describe the file's header row and make up the values.
- **Code contributions (pull requests) are not being accepted at this time.**
  This keeps the project under a single copyright holder. If you have a fix,
  describe it in an issue and it may be implemented.
- **Security issues:** please report privately via the repository's
  "Report a vulnerability" (GitHub Security Advisories) instead of a public
  issue.

You are free to fork Greenwick under the terms of the GNU GPL v3.0 (see
`LICENSE` and `NOTICE`).
