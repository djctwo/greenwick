Privacy

Last updated: October 27, 2026

Greenwick is a free, open-source Mac app. It has no servers, no accounts and no analytics. Your trading journal stays on your Mac, encrypted. Online features are optional, off by default, and use keys you add yourself.

This page explains what the app stores, what it can send over the network, and when. Because the source code is public, you can check every statement here yourself.

01What stays on your Mac

  • Your journal: trades, notes, tags, emotions, checklists and your prop-firm account size and limits are kept in ~/Library/Application Support/Greenwick/Greenwick.sqlite. The file is encrypted with AES-256-GCM and is never written to disk unencrypted; Greenwick decrypts it into memory only while it runs.
  • Trade screenshots: stored in ~/Library/Application Support/Greenwick/Screenshots/ encrypted (AES-256-GCM) with the journal's key since version 1.0.1, and decrypted in memory only to show them. Backups don't include screenshot images.
  • The encryption key: kept in your macOS Keychain. With App Lock on, the key is sealed with your password (PBKDF2-SHA256, 600,000 rounds), so the journal can't be decrypted without it.
  • API keys you add (Anthropic, Finnhub): stored in your macOS Keychain.
  • Preferences: watchlist symbols, checklist rules, the inactivity lock setting and display preferences are kept in Greenwick's ordinary preferences file, which is not encrypted.

02What Greenwick does not do

  • No account, no sign-up, no subscription
  • No telemetry or usage analytics
  • No cloud sync and no server that receives your data
  • No ads
  • No automatic update checks; new versions are published on GitHub Releases

03Optional online services

Greenwick works fully offline. The two services below are off by default and run only with a key you add in Settings. Data goes directly from your Mac to the provider over HTTPS with certificate pinning; nothing passes through anyone else. As with any internet request, the provider also sees your IP address.

3a. AI recommendations: what is sent to Anthropic

AI analysis needs two things: your own Anthropic API key, and the Allow AI analysis switch turned on in Settings. Then, each time you click Run Analysis in the Edge Report, Greenwick sends summary statistics: overall totals, and P&L by session, hour, ticker and weekday. Anthropic bills the run to your own account.

Never sent: individual trades, notes, tags, screenshots or account details. Nothing is sent without your key, the switch and your click. Anthropic's handling of API requests is covered by Anthropic's privacy policy.

3b. Quotes and ticker search: what is sent to Finnhub

If you add your own Finnhub key (free at finnhub.io), the Browse and Watchlist screens fetch quotes and company details. Greenwick sends the ticker symbols you look up or keep on your watchlist, and the text you type into ticker search. Testing your key in Settings requests one quote (AAPL). Nothing from your journal is sent. Finnhub's own privacy policy applies to those requests.

04Security

  • Journal encrypted on disk with AES-256-GCM, decrypted into memory only
  • Optional App Lock: locks when Greenwick goes to the background and after a time without keyboard or mouse activity (off, 1, 5, 15, 30 or 60 minutes; 15 by default)
  • Older-copy check: if the journal file is replaced by an older copy, Greenwick asks before opening it
  • Password-protected backups (AES-256-GCM, PBKDF2-SHA256 with 600,000 rounds), validated before every restore

Not encrypted: CSV and PDF exports, and backups made without a password. A backup without a password can be read by anyone who gets the file. The full security model, including what Greenwick does not protect against, is in SECURITY.md.

05Your control

Your data is local, so you control it directly: export it as CSV or PDF, back it up and restore it, or delete it. Deleting the app leaves the data in place; delete the ~/Library/Application Support/Greenwick/ folder to remove it. There is no other copy.

06This website

This site is a static site hosted on GitHub Pages. It sets no cookies, has no analytics, tracking scripts or forms. Like any website, the host (GitHub) receives standard request data such as your IP address, and the pages load their fonts from Google Fonts, which receives the same. Downloads and the source code are on GitHub, where GitHub's own privacy statement applies.

07Changes

If the app's behavior changes, this page and the repository's README will be updated, and the date at the top will change.

08Contact

Questions: open an issue at github.com/djctwo/greenwick/issues. Please never post real trades, account numbers or API keys there.

Security problems: report them privately through the repository's private vulnerability reporting, not in a public issue.
